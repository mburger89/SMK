# Swift 6.4 Embedded Adoption Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. In this project each **phase** is executed as one Workflow run (see "Execution model" at the end); tasks marked *(parallel group X)* may run concurrently inside that run because they own disjoint files.

**Goal:** Move all 11 SMK firmware builds to Swift 6.4.0-RELEASE and adopt every applicable Embedded Swift feature (stable attributes, swift-mmio, InlineArray/Span, typed throws, existentials, `~Copyable`) with no behaviour change except the approved 256-position matrix cap.

**Architecture:** Five gated phases on branch `swift-6.4-adoption`. Phase 0 adds a shared toolchain finder and a build/size gate script; every later phase must keep all 11 builds green, `swift test` green, exported C symbols stable (where stated), and each target within +2 % flash/RAM of the Phase 0 6.4 baseline.

**Tech Stack:** Embedded Swift 6.4.0-RELEASE, CMake/Ninja, ESP-IDF 6.0.1, pico-sdk, nRF5 SDK, TinyUSB, BTstack, swift-mmio 0.1.1, Swift Testing.

**Spec:** `docs/superpowers/specs/2026-10-09-swift-6.4-embedded-adoption-design.md`

## Global Constraints

- Toolchain floor: `swiftc --version` ≥ **6.4**; dev snapshots only with `-DSMK_ALLOW_SNAPSHOT=ON`.
- Size budget: per target, flash (`text + data`) and static RAM (`data + bss`) ≤ **+2 %** vs. the Phase 0 **6.4** baseline row in `docs/superpowers/notes/swift64-sizes.md`.
- The 11 gate targets: `esp32c6, pico, pico_w, pico2, pico2_w, smk_kbd_rp2040, nrf52840dk, feather_nrf52840, samd21, stm32f4, stm32wb`.
- Keep `-enable-experimental-feature Embedded` and `-enable-experimental-feature Extern` (both still experimental in 6.4).
- Keep the 7 `_swift_stdlib_*` Unicode stubs and `posix_memalign` (still required in 6.4).
- Wire/keymap format unchanged: `PayloadBuilder`, `generate_default_keymap.sh`, `builderMatchesShellGenerator` untouched.
- Matrix cap: `rowCount × colCount ≤ 256` (`smkMaxMatrixPositions = 256`).
- No async/concurrency (`_Concurrency` does not ship for armv6m/riscv32).
- Any new `Sources/SMKCore/*.swift` file is added to **all six** CMake lists: `main/CMakeLists.txt`, `ports/{rp2040,nrf52840,samd21,stm32f4,stm32wb}/CMakeLists.txt`.
- Host tests: `SMK_HOST_TESTS_ONLY=1 swift test`.

## Review Focus

1. **Truncated/corrupt stored keymap must not trap.** `Span` subscripts are bounds-checked and *trap* (hard fault on device) where the old pointer code relied on explicit guards. Every prefix of a valid payload must make `decodeKeymapPayload` **throw**, never crash — pinned in Task 3.4.
2. **Factory reset still reads row 0 / col 0.** `matrix.scan()[0]` becomes `matrix.scan()[0]` on a `KeyBitset`; position 0 must still mean row 0, col 0 for both `colsAreDriven` orientations — pinned in Task 3.3.
3. **Send-on-change must notice a change in the last key slot.** Hand-written `HIDReport ==` over `InlineArray<6, UInt8>` must compare all six slots; a report differing only in `keys[5]` must be sent — pinned in Task 3.2.
4. **Feather (no BLE transport) in Bluetooth mode must not crash.** With `ble == nil`, routing a report must be a no-op — pinned in Task 4.2 (`TransportRouter`).
5. **Matrix settle delay must survive optimisation.** `KeyMatrix.scan()`'s `for _ in 0...50 { }` is an empty loop LLVM deletes (same class as the ClockInit poll bug); without a real delay, ghost/missed keys appear on real boards — fixed and disassembly-checked in Task 2.4.

```bash
#!/bin/bash
# tools/build_all.sh — the gate every phase of the Swift 6.4 adoption must pass.
# Clean-builds all 11 targets into build_gate/<target> (never touches your
# own build*/ dirs), runs host tests, records sizes and exported symbols.
# Written for macOS /bin/bash 3.2: no associative arrays.
set -euo pipefail
cd "$(dirname "$0")/.."

NOTES=docs/superpowers/notes/swift64-sizes.md
ALL=(esp32c6 pico pico_w pico2 pico2_w smk_kbd_rp2040 nrf52840dk feather_nrf52840 samd21 stm32f4 stm32wb)
TARGETS=("${ALL[@]}")
LABEL="$(git rev-parse --short HEAD)"; BASELINE=""; CHECK_POLLS=0; SYMBASE=0
while [ $# -gt 0 ]; do
  case "$1" in
    --baseline) BASELINE="$2"; LABEL="$2"; shift 2 ;;
    --label) LABEL="$2"; shift 2 ;;
    --only) IFS=, read -r -a TARGETS <<< "$2"; shift 2 ;;
    --check-polls) CHECK_POLLS=1; shift ;;
    --symbols-baseline) SYMBASE=1; shift ;;
    *) echo "unknown arg $1" >&2; exit 2 ;;
  esac
done

ARM=/opt/homebrew/opt/arm-gcc-bin@14/bin; export PATH="$ARM:$PATH"
ESPBIN=$(ls -d "$HOME"/.espressif/tools/riscv32-esp-elf/*/riscv32-esp-elf/bin 2>/dev/null | head -1)
: "${PICO_SDK_PATH:=$HOME/pico-sdk}" "${TINYUSB_PATH:=$HOME/tinyusb}" "${CMSIS_CORE_PATH:=$HOME/CMSIS_6}"
: "${CMSIS_F4_PATH:=$HOME/cmsis-device-f4}" "${CMSIS_WB_PATH:=$HOME/cmsis-device-wb}" "${BTSTACK_PATH:=$HOME/btstack}"
: "${STM32CUBEWB_PATH:=$HOME/STM32CubeWB}" "${NRF5_SDK_PATH:=$HOME/nRF5_SDK}" "${NRFXLIB_PATH:=$HOME/sdk-nrfxlib}"
export PICO_SDK_PATH TINYUSB_PATH CMSIS_CORE_PATH CMSIS_F4_PATH CMSIS_WB_PATH BTSTACK_PATH STM32CUBEWB_PATH NRF5_SDK_PATH NRFXLIB_PATH
GCC=(-DCMAKE_C_COMPILER=$ARM/arm-none-eabi-gcc -DCMAKE_CXX_COMPILER=$ARM/arm-none-eabi-g++ -DCMAKE_ASM_COMPILER=$ARM/arm-none-eabi-gcc)

elf_of() {
  case $1 in
    esp32c6) echo build_gate/$1/my_swift_keyboard.elf ;;
    pico|pico_w|pico2|pico2_w|smk_kbd_rp2040) echo build_gate/$1/smk_rp2040.elf ;;
    nrf52840dk|feather_nrf52840) echo build_gate/$1/smk_nrf52840 ;;
    *) echo build_gate/$1/smk_$1 ;;
  esac
}
tool_of() { if [ "$1" = esp32c6 ]; then echo "$ESPBIN/riscv32-esp-elf-$2"; else echo "$ARM/arm-none-eabi-$2"; fi; }

build_one() {
  local t=$1 d=build_gate/$1
  rm -rf "$d"; mkdir -p build_gate
  case $t in
    esp32c6)
      ( . "$HOME/.espressif/v6.0.1/esp-idf/export.sh" >/dev/null
        idf.py -B "$d" -DIDF_TARGET=esp32c6 build ) >"$d.log" 2>&1 ;;
    pico|pico_w|pico2|pico2_w|smk_kbd_rp2040)
      local pb=$t; [ "$t" = smk_kbd_rp2040 ] && pb=pico
      { cmake -G Ninja -S ports/rp2040 -B "$d" -DPICO_BOARD=$pb -DSMK_TARGET_BOARD=$t "${GCC[@]}" && ninja -C "$d"; } >"$d.log" 2>&1 ;;
    nrf52840dk|feather_nrf52840)
      { cmake -G Ninja -S ports/nrf52840 -B "$d" -DSMK_TARGET_BOARD=$t && ninja -C "$d"; } >"$d.log" 2>&1 ;;
    samd21|stm32f4|stm32wb)
      { cmake -G Ninja -S ports/$t -B "$d" && ninja -C "$d"; } >"$d.log" 2>&1 ;;
  esac
}

fail=0; FLASH=(); RAM=()
for i in "${!TARGETS[@]}"; do
  t=${TARGETS[$i]}
  if build_one "$t" && [ -f "$(elf_of "$t")" ]; then
    elf=$(elf_of "$t")
    read -r f r < <("$(tool_of "$t" size)" -B "$elf" | awk 'NR==2 {print $1+$2, $2+$3}')
    FLASH[$i]=$f; RAM[$i]=$r
    "$(tool_of "$t" nm)" -g --defined-only "$elf" | awk '{print $NF}' | sort > "build_gate/$t/symbols.txt"
    [ $SYMBASE = 1 ] && cp "build_gate/$t/symbols.txt" "docs/superpowers/notes/symbols-$t.txt"
    echo "PASS build $t  flash=$f ram=$r"
  else
    echo "FAIL build $t  (see build_gate/$t.log)"; fail=1; FLASH[$i]=FAIL; RAM[$i]=FAIL
  fi
done

if SMK_HOST_TESTS_ONLY=1 swift test >build_gate/swift-test.log 2>&1; then echo "PASS swift test"; else echo "FAIL swift test (build_gate/swift-test.log)"; fail=1; fi

if [ $CHECK_POLLS = 1 ]; then
  while IFS=: read -r t fn; do
    case "$t" in ''|\#*) continue ;; esac
    body=$("$(tool_of "$t" objdump)" -d --no-show-raw-insn "$(elf_of "$t")" | awk -v f="<$fn>:" '$2==f{p=1;next} p&&/^$/{exit} p')
    if [ -n "$body" ] && echo "$body" | grep -qE '[[:space:]]b(ne|eq|cc|cs|mi|pl|hi|ls|ge|lt|gt|le)(\.n|\.w)?[[:space:]]'; then
      echo "PASS poll $t:$fn"
    else
      echo "FAIL poll $t:$fn (missing, or no conditional branch: loop deleted?)"; fail=1
    fi
  done < tools/poll_functions.txt
fi

# Rows always use the canonical 11-column order; targets not built this run are "-".
if [ ! -f "$NOTES" ]; then
  { echo "# Swift 6.4 adoption — gate sizes"; echo; echo "flash = text+data, ram = data+bss (bytes). Cells: flash/ram."; echo
    printf '| label |'; for t in "${ALL[@]}"; do printf ' %s |' "$t"; done; echo
    printf '|---|'; for t in "${ALL[@]}"; do printf -- '---|'; done; echo; } > "$NOTES"
fi
row="| $LABEL |"
for t in "${ALL[@]}"; do
  cell="-"
  for i in "${!TARGETS[@]}"; do [ "${TARGETS[$i]}" = "$t" ] && cell="${FLASH[$i]}/${RAM[$i]}"; done
  row="$row $cell |"
done
echo "$row" >> "$NOTES"

if [ -z "$BASELINE" ]; then
  base=$(grep '^| 6.4-baseline |' "$NOTES" | head -1 || true)
  if [ -z "$base" ]; then echo "FAIL no 6.4-baseline row yet"; fail=1; else
    for i in "${!TARGETS[@]}"; do
      t=${TARGETS[$i]}; f=${FLASH[$i]}; r=${RAM[$i]}; [ "$f" = FAIL ] && continue
      col=0; for j in "${!ALL[@]}"; do [ "${ALL[$j]}" = "$t" ] && col=$((j + 3)); done
      cell=$(echo "$base" | awk -F'|' -v c=$col '{gsub(/ /,"",$c); print $c}')
      bf=${cell%/*}; br=${cell#*/}
      if [ $((f * 100)) -gt $((bf * 102)) ] || [ $((r * 100)) -gt $((br * 102)) ]; then
        echo "FAIL size $t flash $bf->$f ram $br->$r (>2%)"; fail=1
      else echo "PASS size $t flash $bf->$f ram $br->$r"; fi
    done
  fi
fi
exit $fail
```

```cmake
# cmake/FindEmbeddedSwiftc.cmake
# One toolchain finder for every SMK build. Order:
#   1. -DSWIFTC_PATH=... (cache)   2. $ENV{SWIFTC_PATH}
#   3. newest *release* toolchain in ~/Library/Developer/Toolchains or
#      /Library/Developer/Toolchains that passes both probes for <triple>.
# Snapshots (swift-DEVELOPMENT-SNAPSHOT-*) are skipped unless
# SMK_ALLOW_SNAPSHOT=ON; swift-latest is skipped (symlink duplicate).
# Any chosen compiler must report version >= SMK_MIN_SWIFT_VERSION.
set(SMK_MIN_SWIFT_VERSION "6.4" CACHE STRING "Minimum Swift version")
option(SMK_ALLOW_SNAPSHOT "Allow swift-DEVELOPMENT-SNAPSHOT toolchains" OFF)

function(_smk_swiftc_version sc out)
    execute_process(COMMAND "${sc}" --version OUTPUT_VARIABLE _v ERROR_QUIET)
    string(REGEX MATCH "Swift version ([0-9]+\\.[0-9]+(\\.[0-9]+)?)" _m "${_v}")
    set(${out} "${CMAKE_MATCH_1}" PARENT_SCOPE)
endfunction()

function(_smk_swiftc_probe sc triple out)
    set(_src "${CMAKE_BINARY_DIR}/_smk_toolchain_probe.swift")
    file(WRITE "${_src}" "public func _smkToolchainProbe() {}\n")
    execute_process(
        COMMAND "${sc}" -target ${triple} -enable-experimental-feature Embedded -print-target-info
        RESULT_VARIABLE _a OUTPUT_QUIET ERROR_QUIET)
    execute_process(
        COMMAND "${sc}" -target ${triple} -enable-experimental-feature Embedded
                -parse-as-library -typecheck "${_src}"
        RESULT_VARIABLE _b OUTPUT_QUIET ERROR_QUIET)
    if(_a EQUAL 0 AND _b EQUAL 0)
        set(${out} TRUE PARENT_SCOPE)
    else()
        set(${out} FALSE PARENT_SCOPE)
    endif()
endfunction()

function(smk_find_embedded_swiftc triple)
    if((NOT SWIFTC_PATH OR NOT EXISTS "${SWIFTC_PATH}") AND DEFINED ENV{SWIFTC_PATH} AND EXISTS "$ENV{SWIFTC_PATH}")
        set(SWIFTC_PATH "$ENV{SWIFTC_PATH}" CACHE PATH "Path to swiftc" FORCE)
    endif()

    if(NOT SWIFTC_PATH OR NOT EXISTS "${SWIFTC_PATH}")
        set(_cands "")
        foreach(_dir "$ENV{HOME}/Library/Developer/Toolchains" "/Library/Developer/Toolchains")
            file(GLOB _tcs "${_dir}/*.xctoolchain")
            foreach(_tc ${_tcs})
                get_filename_component(_name "${_tc}" NAME)
                if(_name STREQUAL "swift-latest.xctoolchain")
                    continue()
                endif()
                if(_name MATCHES "DEVELOPMENT-SNAPSHOT" AND NOT SMK_ALLOW_SNAPSHOT)
                    continue()
                endif()
                set(_sc "${_tc}/usr/bin/swiftc")
                if(EXISTS "${_sc}")
                    _smk_swiftc_version("${_sc}" _ver)
                    if(_ver)
                        list(APPEND _cands "${_ver}|${_sc}")
                    endif()
                endif()
            endforeach()
        endforeach()
        list(SORT _cands COMPARE NATURAL ORDER DESCENDING)
        foreach(_c ${_cands})
            string(REPLACE "|" ";" _parts "${_c}")
            list(GET _parts 1 _sc)
            _smk_swiftc_probe("${_sc}" ${triple} _ok)
            if(_ok)
                set(SWIFTC_PATH "${_sc}" CACHE PATH "Path to swiftc" FORCE)
                break()
            endif()
        endforeach()
    endif()

    if(NOT SWIFTC_PATH OR NOT EXISTS "${SWIFTC_PATH}")
        message(FATAL_ERROR
            "No Swift >= ${SMK_MIN_SWIFT_VERSION} toolchain with an Embedded stdlib for ${triple} found.\n"
            "Install swift-6.4.0-RELEASE or set -DSWIFTC_PATH=<toolchain>/usr/bin/swiftc.")
    endif()
    _smk_swiftc_version("${SWIFTC_PATH}" _ver)
    if(_ver VERSION_LESS SMK_MIN_SWIFT_VERSION)
        message(FATAL_ERROR
            "${SWIFTC_PATH} is Swift ${_ver}; SMK requires >= ${SMK_MIN_SWIFT_VERSION}. "
            "Delete this build dir or pass -DSWIFTC_PATH=<6.4 toolchain>/usr/bin/swiftc.")
    endif()
    set(SMK_SWIFT_VERSION "${_ver}" PARENT_SCOPE)
    message(STATUS "Using Swift ${_ver}: ${SWIFTC_PATH}")
endfunction()
```

```cmake
function(smk_add_swift_mmio out_srcs out_flags)
    get_filename_component(_tc_bin "${SWIFTC_PATH}" DIRECTORY)
```

```swift
// STM32F4 GPIO register access — GPIOB only (see history in git log for why
// one 16-pin port covers the whole matrix). Registers are swift-mmio
// volatile accesses: unlike `.pointee`, a read here is never hoisted,
// merged, or deleted by the optimiser.
//
// GPIOB base 0x4002_0400. Offsets from cmsis-device-f4 GPIO_TypeDef:
//   0x10 IDR (input level), 0x14 ODR (output latch), 0x18 BSRR (set/reset).

@RegisterBlock
struct GPIOPort {
    @RegisterBlock(offset: 0x10) var idr: Register<GPIOWord>
    @RegisterBlock(offset: 0x14) var odr: Register<GPIOWord>
    @RegisterBlock(offset: 0x18) var bsrr: Register<GPIOWord>
}

@Register(bitWidth: 32)
struct GPIOWord {
    @ReadWrite(bits: 0..<32, as: UInt32.self) var value: VALUE
}

struct GPIORegisters {
    static let base: UInt = 0x40020400 // GPIOB
    let port = GPIOPort(unsafeAddress: GPIORegisters.base)

    // BSRR low half: writing 1 sets the output high.
    var outSet: UInt32 {
        get { port.odr.read().value }
        nonmutating set { port.bsrr.write { $0.value = newValue & 0x0000_FFFF } }
    }

    // BSRR high half: writing 1 (shifted to bits 31:16) drives the output low.
    var outClear: UInt32 {
        get { port.odr.read().value }
        nonmutating set { port.bsrr.write { $0.value = (newValue & 0x0000_FFFF) << 16 } }
    }

    var input: UInt32 { port.idr.read().value }
}

let gpio = GPIORegisters()
```

```swift
/// The most key positions (rows × cols) any board may declare. Fixed so
/// scan/debounce state lives in inline storage with no per-tick heap
/// allocation; `decodeKeymapPayload` rejects larger matrices. The largest
/// real board (smk_kbd) uses 60.

/// One bit per matrix position (index = row * colCount + col).
struct KeyBitset: Equatable {
    static let capacity = 256
    private var words: InlineArray<8, UInt32> = .init(repeating: 0)

    init() {}

    subscript(i: Int) -> Bool {
        get { (words[i >> 5] >> UInt32(i & 31)) & 1 == 1 }
        set {
            let mask: UInt32 = 1 << UInt32(i & 31)
            if newValue { words[i >> 5] |= mask } else { words[i >> 5] &= ~mask }
        }
    }

    static func == (lhs: KeyBitset, rhs: KeyBitset) -> Bool {
        for w in 0..<8 where lhs.words[w] != rhs.words[w] { return false }
        return true
    }
}
```

```swift
struct DebouncedMatrix {
    private let totalKeys: Int
    private let debounceThreshold: UInt8 = 5

    private var counters: InlineArray<256, UInt8> = .init(repeating: 0)
    private var stableState = KeyBitset()

    mutating func update(rawScan: KeyBitset) -> KeyBitset {
        for i in 0..<totalKeys {
            if rawScan[i] != stableState[i] {
                counters[i] += 1
                if counters[i] >= debounceThreshold {
                    stableState[i] = rawScan[i]
                    counters[i] = 0
                }
            } else {
                counters[i] = 0
            }
        }
        return stableState
    }
}
```

```swift
/// A way to deliver a keyboard report to the host. Conformers live with
/// their stacks: NimBLE (BleHelper.swift), BTstack (ports/common/
/// BleHidGatt.swift), TinyUSB (ports/*/UsbHid.swift), CH9350 UART
/// (WiredHidUart.swift). Held as `any HIDTransport` (Swift 6.4 Embedded
/// existentials) so the scan loop no longer depends on which C symbols a
/// target happens to define.
protocol HIDTransport {
    func send(_ report: borrowing HIDReport)
}

struct TransportRouter {
    var ble: (any HIDTransport)?
    var wired: (any HIDTransport)?

    func send(_ report: borrowing HIDReport, mode: ConnectionMode) {
        switch mode {
        case .bluetooth: ble?.send(report)
        case .wired: wired?.send(report)
        }
    }
}
```

## Execution model

Each phase runs as **one Workflow** (the user asked for subagents + workflows). Inside a run: implementer agents for tasks in the same *parallel group* run concurrently because they own disjoint files; ungrouped tasks run sequentially; a single verifier agent runs that phase's gate command; then a reviewer agent checks the phase diff against this plan. The orchestrator independently checks `git log`/`git status` after every agent. A red gate stops the run; fixes happen before the next phase. Keep each run under 10 agents:

| Run | Agents |
|---|---|
| Phase 0 | 0.1 (gate + 6.3.1 row) → 0.2 (finder + 6.4 baseline) → 0.3 docs (sequential, 3) + verifier |
| Phase 1 | group A: 1.1 ‖ 1.2, then 1.3 (3) + verifier + reviewer |
| Phase 2a | 2.1 → 2.2 (2) + verifier |
| Phase 2b | group B: 2.3 (5 ports, batched as 2 agents) ‖ 2.4; group C: 2.5 ‖ 2.6 ‖ 2.7 ‖ 2.8; then 2.9 — split into two runs if over 10 agents |
| Phase 3 | 3.0 → 3.1 → 3.2 → 3.3 → 3.4 → 3.5 (sequential, SMKCore-shared), then group D: 3.6 + verifier + reviewer |
| Phase 4 | 4.1 → 4.2 → 4.3 → 4.4 → 4.5 (sequential; shared Main.swift) + reviewer |
| Final | Task 5 (interactive with the maintainer) |
