nRF52840

Arm Cortex-M4F. USB HID (TinyUSB) + BLE HID (Nordic's SoftDevice Controller over BTstack). Build-only for now — not yet verified on real hardware, and the GPIO pin map is an explicit placeholder that must be replaced with schematic-verified pins before ever flashing a real board.

Prerequisites

  • nRF5 SDK (CMSIS device header + Cortex-M4 startup/linker script) at ~/nRF5_SDK — download v17.1.0+ from Nordic and unzip. Only modules/nrfx/mdk/ is used.
  • sdk-nrfxlib (prebuilt SoftDevice Controller + MPSL libraries) at ~/sdk-nrfxlib: git clone https://github.com/nrfconnect/sdk-nrfxlib ~/sdk-nrfxlib.
  • TinyUSB at ~/tinyusb: git clone https://github.com/hathach/tinyusb ~/tinyusb.
  • BTstack at ~/btstack: git clone https://github.com/bluekitchen/btstack ~/btstack.
  • ARM toolchain with newlib — same arm-gcc-bin@14 already required for RP2040.
  • Swift Embedded ARM toolchain — same one already required for RP2040/ESP32-C6.

Build

export NRF5_SDK_PATH=~/nRF5_SDK
export NRFXLIB_PATH=~/sdk-nrfxlib
export TINYUSB_PATH=~/tinyusb
export BTSTACK_PATH=~/btstack

./build_nrf52840.sh

Known gaps: runtime keymap store is a no-op stub (nothing persists across reboots), LE bonding does not survive a reboot, and the millisecond timers are uncalibrated software counters until a real hardware timer is wired up.
