A keyboard firmware written in Embedded Swift.

Eight boards across six MCU families. One codebase. BLE + USB HID.

Get Started View on GitHub
Why SMK
🧬 Real Embedded Swift on bare metal — safety and modern syntax, no VM or GC.
🧩 Layer engine with JSON keymaps — momentary layers, toggles, transparent keys.
🔗 BLE + Wired HID, switchable at runtime with a single dual-mode firmware.
💡 Per-key RGB backlight, opt-in — off by default, on when you wire it up.
Supported Targets
ESP32-C6 ✅ BLE + Wired
RP2040 (Pico) ✅ USB HID
RP2040 (Pico W) ✅ USB + BLE scaffolded
RP2350 (Pico 2 / 2 W) 🚧 build-only
smk_kbd_rp2040 ✅ USB + RGB
nRF52840 🚧 build-only
STM32F4 🚧 build-only
STM32WB 🚧 build-only
Quick Start
idf.py set-target esp32c6 && idf.py build && idf.py flash monitor

That's the ESP32-C6 path — SMK's primary, hardware-verified board. See the full docs for every target's prerequisites and build commands.
