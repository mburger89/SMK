RP2040 / RP2350

Covers the Raspberry Pi Pico (USB HID), Pico W (USB HID + BLE scaffolded), their RP2350-based successors Pico 2 / Pico 2 W (build-only, not yet hardware-verified), and the chip-down smk_kbd_rp2040 board (RP2040 + CYW43439 — USB HID + per-key RGB working, BLE not yet hardware-confirmed). One shared codebase, only the hardware platform layer differs per board.

Prerequisites

  • pico-sdk at ~/pico-sdk with submodules initialized (git -C ~/pico-sdk submodule update --init).
  • ARM toolchain with newlib: brew tap osx-cross/arm && brew install osx-cross/arm/arm-gcc-bin@14.
  • cmake ≥ 3.29, ninja, picotool: brew install cmake ninja picotool.
  • Swift ≥ 6.3 Embedded ARM toolchain, installed in ~/Library/Developer/Toolchains/.
  • RP2350 only (pico2/pico2_w): additionally requires a Swift development-snapshot toolchain (confirmed working: swift-DEVELOPMENT-SNAPSHOT-2026-05-27-a or later) that ships a real Embedded-Swift stdlib for armv8m.main-none-none-eabi. Released swift-6.3.x toolchains report support for that triple but fail an actual compile — they don't ship the stdlib.

Build & Flash

export PICO_SDK_PATH=~/pico-sdk

./build_rp2040.sh pico      # plain Pico — USB HID only
./build_rp2040.sh pico_w    # Pico W — USB HID + BLE (scaffolded)
./build_rp2040.sh pico2     # Pico 2 — USB HID only
./build_rp2040.sh pico2_w   # Pico 2 W — USB HID + BLE
./build_rp2040.sh smk_kbd_rp2040   # custom PCB — USB HID + RGB + BLE-over-UART

Produces build_rp2040_<board>/smk_rp2040.uf2. Flash by holding BOOTSEL, connecting USB, then:

picotool load -f build_rp2040_pico/smk_rp2040.uf2
