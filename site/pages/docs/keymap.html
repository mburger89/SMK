Keymap Reference

The active keymap is the configJson string literal in Sources/smk/Main.swift. The keymap.json at the repo root is a reference copy only — edits there don't affect the firmware until copied into Main.swift.

Schema

  • matrix — defines rows and cols GPIO pin lists, plus colsAreDriven (0/1): whether columns are the strobed/output side (1) or rows are (0, default). Depends on your diode orientation — see the Architecture page's matrix scan section.
  • layers — an array of layers, each a 2D array of action strings (see below).

Key Action Syntax

SyntaxMeaning
key:<char>Standard keycode, e.g. key:a, key:enter
mod:<name>Modifier, e.g. mod:leftShift
mo:<n>Momentary layer n — active while held
tg:<n>Toggle layer n
transTransparent — falls through to the layer below
toggle_connSwitch between BLE and wired modes
noneNo action
